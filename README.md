# nimitgotnolimit.com

Personal site of Nimit Jain, Founder & CEO of [Insturix](https://insturix.com).

Static, single file, no build step. Open `index.html` in a browser. The fonts (Archivo, Inter, JetBrains Mono) load from Google Fonts.

- `index.html`: the whole site
- `portrait.webp` and `portrait.jpg`: hero portrait
- `og.jpg`: link-preview image, 1200 by 630
- `sitemap.xml` and `robots.txt`: search engines
- `CNAME`: custom domain for GitHub Pages
